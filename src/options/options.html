General Annoyance Filter

Features stay on by default. When a site breaks, exclude it into the review backlog — that list is a work queue, not a graveyard. Right-click any object → GAF: Save object for inspection to archive HTML and escape hints.

Media & motion

Time freeze (soft paywalls)

Soft walls (e.g. The Telegraph) often load the article first, then a timer or script blurs/removes it. Slow stretches page timers so you keep a long window for Reader Mode or Save as PDF. Stop + snapshot also captures a reading clone of the page you can keep after the live DOM is ruined.

Free-article meter (cookies)

Some sites (e.g. spiked-online.com) count free reads in cookies — opening Incognito “works” because the counter is empty. Reset meter clears site cookies (and optional storage) then reloads. Same idea as forgetting the site; you may need to log in again if you had a membership session.
